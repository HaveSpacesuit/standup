Proposals

1Calm canvas & focus columns

Spend color, width, and detail where the conversation happens.

What changes

  • Remove full-column tints. Color stays on each column's header bar and card edges.
  • Elastic columns: Active and Review get about 25% more width. Done narrows.
  • Empty Blocked collapses into a 44px rail marked “clear.” It expands automatically when something is blocked, and becomes the only tinted column.
  • Per-column density: New and Done use compact cards. Active, Review, and Blocked keep full cards.

Why

  • Tints repeat what card edges already say. A loud pink column with “0” draws attention for nothing.
  • Today Blocked (0) and Done (2) take 40% of the board width.
Keeps: 5 columns, order, colors, counts, “Show more”Size: S–M

2Sprint ribbon (retire the footer)

Show sprint context first, in one slim row, so the board gets more height.

What changes

  • One 42px ribbon under the toolbar shows sprint name and dates, a day-of-sprint progress bar, and a stacked effort bar. The bar replaces the five “Current sprint effort: N” lines.
  • The ribbon also holds the existing forecast chip and popover, plus a readable effort-flow sparkline that opens the existing chart dialog.
  • Next sprint becomes a muted note. Iteration paths move to tooltips.
  • Column headers shrink to one line: name, count, points.
  • Header tidy-up: search icon plus a / hint, labeled “People | Sprint” view toggle, and “Synced 2m ago” beside Refresh.
Net: about 70px more board heightKeeps: every footer datum, forecast popover, chart dialogSize: M

3Lane summaries & collapsible lanes

Make the 175px “Team member” column work: answer “how loaded is this person, and is anything wrong?” without scanning cards.

What changes

  • Each lane header shows a load bar (cards per column, in column colors), open cards and sprint points, and up to two attention flags (failing check, idle, needs approval, with QA).
  • Lanes collapse to a 36px summary row with per-column counts and signal icons. Collapse-all and expand-all live in the corner cell.
  • The lane header stays sticky while you scroll a tall lane.
Keeps: rows pinned to the main developer, Unassigned rows, member hiding optionsSize: M

4Attention bar (triage facets)

Turn “scan 60 cards” into “click one chip.”

What changes

  • Chips for Blocked, Failing checks, Needs approval, Idle 3+ days, With QA, Ready to complete, Changed since yesterday, each with a live count.
  • Selecting a chip dims non-matching cards in place, so the board shape and pinning stay intact. Column headers show “matches / total.” Matching cards move to the top of each cell, so they're never hidden behind “Show more.”
  • It works with the quick filter and member filter. Counts come from signals cards already compute (next step, aging, change highlights), so it needs no new ADO queries.
Size: S–MPairs with: 3 (lane flags use the same signals)

5Standup mode

Make the page's real use, walking the board one developer at a time, a first-class mode.

What changes

  • Start standup replaces the ▲▼ member-cycle buttons. Ctrl+↑/↓ still work.
  • A presenter bar shows who's up (“3 of 6”), a per-person timer, the queue with check marks, Previous and Next, and the order: alphabetical or most attention first.
  • The speaker's lane expands fully, with no “Show more,” and gets an accent outline. Everyone else collapses to summaries (with 3) or dims (without 3).
Keeps: the developer-pinned rows as the organizing principleSize: M–LBuilds on: 3

Suggested sequencing

  • First: 1 + 2. Mostly layout and styling, low risk, immediate calm, and about 70px more board height.
  • Next: 4. Highest value per line of code, because the signals already exist on cards.
  • Then: 3. Lane flags reuse 4's signal logic, and collapsing lanes makes larger teams usable.
  • Last: 5. Built from 3 (collapsed lanes) and 4 (attention ordering).

Quick wins, any time

  • Show “Synced 2m ago” next to Refresh, and spin the icon while loading.
  • Label the View toggle (“People | Sprint”). Its two icons are ambiguous today.
  • Move “Manage team” into the Team menu to shorten the icon row.
  • Show the member count in the “Team member” corner cell.
